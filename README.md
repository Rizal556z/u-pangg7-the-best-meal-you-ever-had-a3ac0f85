## Entry

> My grandmother's rendang, slow-cooked six hours in coconut milk until the beef fell apart, eaten with warm rice on her kitchen floor while rain drummed on the tin roof, is the best meal I ever had.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the sentence to `/output/entry.txt` and prints it. It guards the entry to 1–200 characters and a single sentence before writing.

Run it:

```sh
python3 main.py
```
